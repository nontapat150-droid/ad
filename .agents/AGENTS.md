# Project AI Instructions (Rules)

ไฟล์นี้คือ Workspace Customization ที่ AI จะอ่านโดยอัตโนมัติในทุกครั้งที่เข้ามาทำงานในโปรเจคนี้ 
ใช้สำหรับระบุคำแนะนำ (Instructions), กฎเกณฑ์ (Rules), และบริบทของโปรเจค 

## 1. ข้อมูลทั่วไปของโปรเจค (Project Context)
- **ประเภทโปรเจค:** ระบบ Backend / Web Application
- **เทคโนโลยีหลัก:** Node.js, JavaScript, Database (เช่น MySQL ผ่าน XAMPP)
- **ตำแหน่งไฟล์สำคัญ:** 
  - `backend/` - โฟลเดอร์สำหรับ Backend
  - `test-db.js` - ไฟล์ทดสอบการเชื่อมต่อฐานข้อมูล

## 2. กฎการเขียนโค้ด (Coding Standards & Rules)
- เขียนโค้ดให้อ่านง่าย เป็นระเบียบ และมี Comment อธิบายส่วนที่ซับซ้อน
- ตรวจสอบและจัดการ Error อย่างรัดกุมเสมอ โดยเฉพาะการเชื่อมต่อ Database
- หลีกเลี่ยงการ Hardcode รหัสผ่านหรือข้อมูลสำคัญ ให้ใช้ไฟล์ `.env` เสมอ

## 3. ขั้นตอนการทำงาน (Workflow)
- เมื่อมีการแก้ไขไฟล์ ให้ตรวจสอบผลกระทบที่อาจเกิดขึ้นกับส่วนอื่นของระบบ
- หากมีการเปลี่ยนแปลงเกี่ยวกับ Database ให้ระบุหรือบันทึกโครงสร้าง (Schema) ที่เปลี่ยนไปให้ชัดเจน
